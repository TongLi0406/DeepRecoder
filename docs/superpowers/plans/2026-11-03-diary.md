# Diary Implementation Plan

> Execute inline with executing-plans and test-driven-development. No commits or
> worktrees: this workspace has no Git repository and the user approved in-place work.

**Goal:** Bound long-recording processing and add consented Android diary capture.

**Architecture:** Keep the existing session API. Add a shared bounded-text utility,
persisted chunk checkpoints, and a separate diary store. A native foreground
service owns speech files; JS drains them serially and generates sourced diaries.

**Tech Stack:** Expo SDK 56, TypeScript, SQLite, Kotlin, sherpa-onnx, Node test runner.
